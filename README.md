# Engenharia de Software Seguro — Projeto Nexora

Bem-vindo ao repositório do **Grupo 19** para a disciplina de Engenharia de Software Seguro. 

Nosso projeto consiste na modelagem de segurança, análise de riscos e especificação de segurança da **Nexora**, uma plataforma de aprendizagem e ensino online voltada para cursos profissionalizantes e tecnologia.

## Estrutura de Pastas do Repositório

A organização física das pastas do repositório segue as recomendações de boas práticas de engenharia de software:

```
ess-nexora/
├── README.md                   # Esta página inicial do projeto
├── docs/                       # Relatórios técnicos em Markdown de cada etapa
│   ├── etapa-1-ameacas-stride.md
│   ├── etapa-2-riscos-nist.md
│   └── ...
├── diagramas/                  # Imagens e arquivos editáveis
│   └── ...
├── codigo/                     # Protótipos de código seguro ou pseudocódigos
│   └── ...
├── evidencias/                 # Logs de testes e relatórios de varredura
│   └── ...
└── roteiros/                   # Textos das etapas conceituais (IDS e DevSecOps)
```
